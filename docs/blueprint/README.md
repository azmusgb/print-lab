# Print Lab — delivery package

Start with Print-Lab-Blueprint.docx or the editable Markdown. The HTML edition has a linked contents list.

- Print-Lab-Blueprint.md / .html / .docx: complete review, requirements, architecture, experiment recovery and delivery plan.
- Requirements.csv: 34 prioritized requirements with acceptance criteria.
- Acceptance-Tests.csv: 14 traceable verification scenarios.
- source-manifest.json: source snapshot and inspected-file hashes.

Editable Figma: https://www.figma.com/design/ZDNyoPD0ZQRLEWw6NtmFPi

Ten static editable design boards, semantic variables and reusable action/state foundations. These are design proposals, not a wired interactive prototype or implemented product. Illustrative specimens and numbers are not experimental evidence.

The repository was read, not modified. Tests were not run because a production-targeting test needs isolation first. Delivery estimates are planning assumptions, with physical print cycles additional.

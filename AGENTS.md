# Rules for coding agents in print-lab

These hold for every agent (Claude Code, Codex, others).

- **Read `CLAUDE.md` in this folder first.** It holds this repository's rules (the checks to run, how changes land,
  and what an agent may and may not do with a print); they apply to every agent, not only Claude.
- **Read the Home Platform design contract before any UI work**: appliance-ui `DESIGN.md`
  (https://github.com/azmusgb/appliance-ui/blob/main/DESIGN.md). Read it at the start of the task, not from memory or
  from this summary. Pi Hub's baseline and its approved amendments win where they differ. If you can't open it (no
  network, no access), say so and stop before changing a screen.
